# 📖 Guide

## ⚙️ Installation (une fois)
1. Ouvre le dossier **Savoir** comme vault dans Obsidian.
2. ⚙️ → Modules complémentaires → installe et active **Dataview**.
3. ⚙️ → Dataview → active **Enable JavaScript Queries**.
4. Ferme complètement Obsidian et rouvre-le.

## 🔁 Comment l'utiliser
1. **Choisir quoi apprendre** : ouvre un domaine, regarde son *Plan d'apprentissage*.
2. **Créer la notion** : tape son nom dans l'Accueil (ou dans le domaine), choisis le domaine, ➕.
3. **La remplir** dans l'ordre : *problème → comment ça marche → exemple → limites*. Remplis `resume` en haut : une phrase, elle s'affiche dans les listes.
4. **Changer le statut** avec les boutons en haut de la note : ⚪ À apprendre → 🟡 En cours → 🟢 Maîtrisé.
5. **Cocher** la ligne dans le plan du domaine.
6. **Réviser** : chaque semaine, ouvre 2 ou 3 notions de « 🔁 À revoir », relis, puis 🔁 Revu aujourd'hui.

## 📌 Les règles
- **Une note = une notion.** « JWT », pas « Sécurité web ».
- **Avec tes mots.** Pas de copier-coller de doc.
- **Un exemple obligatoire**, idéalement tiré de ton travail.
- **Maîtrisé = je peux l'expliquer sans relire.**
- **Relie les notions** dans « Liens » avec `[[...]]`, seulement vers des notes qui existent.

## 🗂️ Structure
- `Notions/` : un dossier par domaine (01 à 14), chacun avec sa page et son plan.
- [[Carnet d'erreurs]] : chaque erreur résolue en une ligne, message → cause → solution.
- `Templates/` et `Systeme/` : le moteur, **ne touche pas**.
