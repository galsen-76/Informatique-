# Révisions

> [!info] Comment réviser
> Ouvre une fiche due, va à la section **6 · Réviser**, réponds à voix haute **avant** de déplier chaque question. Ensuite repousse `next_review` : +1 j → +3 → +7 → +14 → +30 (retour à +1 j si tu as séché).

```dataviewjs
await dv.view("10 — Templates/Scripts/learning", { view: "revisions" })
```

## Toutes les questions de révision
Dans chaque fiche concept, section *6 · Réviser*. Recherche globale : `Ctrl+Shift+F` puis `[!question]`.
