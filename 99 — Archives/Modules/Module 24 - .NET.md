# 24 · .NET et C#

> [!tip] Pourquoi à cette place dans le parcours
> Un deuxième langage, compilé et typé, pour les projets qui sont en .NET. Il faut déjà savoir lancer des commandes dans le terminal et savoir ce qu'est une API. Les notions (classe, liste, exception, test…) sont les mêmes qu'en Python : seule l'écriture change, et elle est dans l'encadré « Comment ça s'écrit » de chaque fiche.

## Objectifs
- Installer le SDK et créer, lancer, compiler un projet avec la commande `dotnet`
- Comprendre projet, solution et référence entre projets
- Lire et écrire du C# simple : types, classes, listes, LINQ, exceptions, async
- Écrire une petite API web avec ASP.NET Core et la tester avec xUnit
