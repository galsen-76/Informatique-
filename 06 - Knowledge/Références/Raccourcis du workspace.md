# Raccourcis du workspace

| Action | Raccourci |
| --- | --- |
| Palette de commandes | `Ctrl+P` |
| Ouvrir une note | `Ctrl+O` |
| Créer depuis un template | `Alt+N` |
| Insérer un template | `Alt+E` |
| Lecture / édition | `Ctrl+E` |
