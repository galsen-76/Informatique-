# 🛠️ Portfolio

> [!abstract] Objectif
> Un site personnel qui présente tes projets — et qui prouve à lui seul tes bases web (accessibilité, responsive, JS propre).

**Période :** M01 → M03 de la [[Roadmap-12-mois|Roadmap 12 mois]]  
**Stack :** HTML sémantique, CSS (Flex/Grid, variables), JavaScript puis TypeScript, Vite, ESLint/Prettier, GitLab Pages

---

## Jalons

### M01
- [ ] #task Page d'accueil HTML sémantique (header, main, sections, footer)
- [ ] #task Mise en page responsive Flex/Grid, mobile first
- [ ] #task Variables CSS + mode sombre
- [ ] #task Dépôt GitLab, commits conventionnels, README

### M02
- [ ] #task Filtre des projets par technologie en JS vanilla (délégation d'événements)
- [ ] #task Mode sombre persisté dans localStorage
- [ ] #task Section « Films du moment » via une API publique (fetch, gestion d'erreurs, chargement)

### M03
- [ ] #task Migration en TypeScript strict + Vite
- [ ] #task ESLint + Prettier + husky + lint-staged
- [ ] #task Score Lighthouse ≥ 90 (perf, a11y, SEO)
- [ ] #task Déploiement GitLab Pages via pipeline
