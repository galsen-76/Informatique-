# Tâches

Les tâches vivent **uniquement dans les boards Kanban** (`Kanban - <Projet>`). Tu crées et déplaces les cartes là-bas ; cette page, les fiches projet, le dashboard et le calendrier se mettent à jour tout seuls.

> [!tip] Écrire une carte
> - Priorité : `#urgent` ou `#haute`
> - Échéance : tape `@` dans la carte et choisis la date
> - Type (facultatif) : `#bug`, `#doc`, `#dette`…
