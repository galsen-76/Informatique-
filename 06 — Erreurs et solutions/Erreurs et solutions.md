# Erreurs et solutions

Chaque erreur rencontrée une fois ne doit plus coûter de temps la deuxième fois (template **Erreur**). Colle le message exact dans le titre ou le premier bloc : la recherche le retrouvera.

```dataview
LIST WITHOUT ID file.link + " · " + tool
FROM "06 — Erreurs et solutions"
WHERE type = "error"
SORT date DESC
```
