# Bonnes pratiques

> [!info] À quoi servent ces fiches
> Pour chaque langage ou outil : ce qu'il faut faire, ce qu'il faut éviter, et surtout **pourquoi**. À relire avant de commencer un projet et avant de valider son travail (chaque fiche finit par une liste de vérification). Modèle : **Bonnes pratiques**.

```dataview
TABLE WITHOUT ID file.link AS "Fiche", length(concepts) AS "Notions liées"
FROM "05 — Fiches pratiques/Bonnes pratiques"
WHERE type = "bonnes-pratiques"
SORT sujet ASC
```

Commence par [[Bonnes pratiques - Code en général]] et [[Bonnes pratiques - Résoudre un problème et déboguer]] : elles valent pour tout le reste.
